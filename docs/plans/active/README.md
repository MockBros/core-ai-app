# Active DeepInterview Execution Plans

Place one evolving plan here when DeepInterview work needs durable memory. Use
[`../../templates/exec-plan.md`](../../templates/exec-plan.md), keep outcome,
authority, scope, progress, decisions, and validation current, and move the
plan to [`../completed/`](../completed/) only after the requested result and
evidence are verified.

Do not use this directory as a task database or invent a parallel lifecycle
record for bounded work that can safely resume from Git.
