# DeepInterview Decisions

Decision records preserve lasting product, architecture, data ownership,
security, compatibility, and validation choices that future work must inherit.

Use [`../templates/decision.md`](../templates/decision.md). Task-local
implementation choices remain in the active execution plan and do not require
a separate decision.

DeepInterview begins with no fabricated decisions. Add a decision here only
when a product, architecture, data-ownership, security, compatibility, or
validation choice is explicitly accepted and future work must inherit it. Keep
observed implementation facts in the owning source or documentation instead,
then index accepted decision documents here.
